# 设计与动画规范

- 黑、白、灰与 Klein 蓝 #2e2ee6；极简、现代、抽象，内容清晰可读。
- 默认卡片圆角 12px；玻璃控件不使用色散。页面不添加上下左右装饰性文本。
- 中文正文：Inter Variable / Inter，配中文系统无衬线回退。英文代码与重点数字：JetBrains Mono。
- 动画卡片：英文 JetBrains Mono；中文实心 Fusion Pixel，通常位于英文上方且具有可读字号。标题位置随构图，整体体系统一。
- 海报通常为透明 RGBA 900×600；12 帧，每帧 110ms，WebP 动画并附静态 PNG。背景由使用容器提供。
- 文字保持静止，主要动效由最多两个图形层的小幅周期运动承担；不要通过大幅全图缩放制造动感。
- 视口外、后台及加载遮罩期间暂停重场景；遵守 reduced-motion。
- 低分辨率粒子背景不代表所有内容可以模糊；保持前景文字与互动原型清晰。
- 文案自然准确，避免无意义口号、虚构效果数字和防御性赘述。

详细历史构图见 HANDOFF.md；本文件及用户最新指令优先。
